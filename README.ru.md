# BomzhHammer (БомжХаммер)

**Languages:** [English](README.md) | [Русский](README.ru.md) | [中文](README.zh-CN.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt-BR.md) | [العربية](README.ar.md) | [日本語](README.ja.md) | [हिन्दी](README.hi.md) | [한국어](README.ko.md)

**Пошаговая карточная стратегия с мрачным сатирическим юмором, где империи бездомных сражаются за контроль над городскими свалками, вокзалами и мусорными баками.**

> Жанр: пошаговая карточная стратегия. Движок: Godot 4.2.2 (GDScript). Платформа: ПК (mobile-first 1080×1920).

## Об игре

BomzhHammer — это пошаговая карточная постапокалиптическая стратегия в мире, который превратился в свалку пластика и мусора. Выберите идеологию, выберите религию, соберите две колоды и сражайтесь с вражеской империей за территории города. Игра выдержана в мрачном сатирическом тоне и предназначена для взрослой аудитории.

## Как играть (Windows)

1. Зайдите в [Releases](https://github.com/zuluchakahuaka-nwc/BomzhHammer/releases) и скачайте `BomzhHammer_v0.2-alpha.zip` из [релиза v0.2-alpha](https://github.com/zuluchakahuaka-nwc/BomzhHammer/releases/tag/v0.2-alpha).
2. Распакуйте архив в любое место.
3. Дважды кликните `Play.bat` — игра запустится.

## Запуск из исходников (для разработчиков)

```bash
git clone https://github.com/zuluchakahuaka-nwc/BomzhHammer
```

Откройте папку проекта в [Godot 4.x](https://godotengine.org/) и нажмите **F5**, чтобы запустить. Арты карт генерируются на лету через бесплатный [Pollinations API](https://pollinations.ai/) (API-ключ не требуется).

## Управление

| Действие | Управление |
|----------|------------|
| Завершить фазу / пропустить | Пробел или Enter |
| Главное меню | Esc |
| Сыграть карту | ЛКМ |
| Информация о карте | ПКМ |
| Выбрать территорию | ЛКМ |
| Язык | Кнопка настроек в меню |

## Возможности

- Система двух колод: управление/ситуации + боевые отряды
- 32 типа отрядов, 67 карт ситуаций, 9 заклинаний, 5 командиров
- 29 территорий на стратегической карте города
- Система идеологий: Алкогольная диктатура против Дерьмократии
- Система религий: Многобомжие, Трезвость, Алкотеизм, Этанольство
- Бой по характеристикам ATK/DEF/HP с броском кубика d6
- ИИ-противник и встроенный режим бота (`--bot`)
- ИИ-генерация артов карт (Pollinations API)
- Языки в игре: русский / английский
