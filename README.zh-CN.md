# BomzhHammer（流浪汉之锤）

**Languages:** [English](README.md) | [Русский](README.ru.md) | [中文](README.zh-CN.md) | [Español](README.es.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Português](README.pt-BR.md) | [العربية](README.ar.md) | [日本語](README.ja.md) | [हिन्दी](README.hi.md) | [한국어](README.ko.md)

**一款带有黑色讽刺幽默的回合制卡牌策略游戏，流浪汉帝国为争夺城市垃圾场、火车站和垃圾桶的控制权而战。**

> 类型：回合制卡牌策略。引擎：Godot 4.2.2（GDScript）。平台：PC（移动优先 1080×1920）。

## 关于游戏

BomzhHammer 是一款循序渐进的卡牌末日策略游戏，背景设定在一个已沦为塑料与垃圾堆积场的世界。选择你的意识形态，选择你的宗教，组建两副牌组，与敌对帝国争夺城市各处的领土。游戏基调黑暗且带有讽刺意味，面向成年玩家。

## 如何游玩（Windows）

1. 前往 [Releases](https://github.com/zuluchakahuaka-nwc/BomzhHammer/releases)，从 [v0.2-alpha 版本](https://github.com/zuluchakahuaka-nwc/BomzhHammer/releases/tag/v0.2-alpha)下载 `BomzhHammer_v0.2-alpha.zip`。
2. 将压缩包解压到任意位置。
3. 双击 `Play.bat` —— 游戏即会启动。

## 从源码运行（开发者）

```bash
git clone https://github.com/zuluchakahuaka-nwc/BomzhHammer
```

在 [Godot 4.x](https://godotengine.org/) 中打开项目文件夹，按 **F5** 开始游戏。卡牌美术通过免费的 [Pollinations API](https://pollinations.ai/) 按需获取（无需 API 密钥）。

## 特色

- 双牌组系统：管理/情境牌组 + 战斗单位牌组
- 32 种单位、67 张情境卡、9 个法术、5 名指挥官
- 战略城市地图上 29 块领地
- 意识形态系统：酒精独裁 vs 民主（Der'mokratiya）
- 宗教系统：多流浪汉神教、清醒派、酒精神教、乙醇主义
- 战斗采用 ATK/DEF/HP 属性并附加 d6 骰子掷点
- AI 对手与内置机器人模式（`--bot`）
- AI 生成的卡牌美术（Pollinations API）
- 游戏内语言：俄语 / 英语
